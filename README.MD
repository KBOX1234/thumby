# How to use

## 1. Install

Copy the thumby exectuable to your /bin folder:
```sh
sudo cp ./thumby /bin
```

## 2. Run as sudo
```sh
sudo thumby
```

### 3. Select the iso
### 4. Select device
### 5. Burn iso

## Info
On linux the status bar my freez for a while while waiting to finish, this is normal since the program is waiting for the writes to finish flushing to the thumb drive.
